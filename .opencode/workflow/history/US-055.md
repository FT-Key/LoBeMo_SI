# US-055: Servicios - Modal + Crear Nuevo

## Trello Card
- **ID**: US-055
- **Board**: LoBeMo Seguridad Informática — MVP
- **List**: En proceso → Done
- **URL**: https://trello.com/c/US-055

## Resumen
Migrar la funcionalidad de creación de servicios desde edición inline a un FormModal con POST endpoint, siguiendo el patrón establecido en el proyecto.

## Problema
- No existía capacidad de crear servicios (solo lectura y edición inline)
- No había POST endpoint para servicios
- No existía schema de validación Zod para servicios

## Cambios realizados

### 1. Schema Zod validación (`src/shared/validation/servicios.ts`)
- `createServicioSchema` con validación:
  - `nombre`: requerido, 3-100 caracteres
  - `descripcion`: opcional, max 500 caracteres
  - `precioBase`: opcional, número positivo

### 2. POST endpoint (`src/app/api/servicios/route.ts`)
- `POST /api/servicios` con validación Zod
- Verificación de nombre único (409 si ya existe)
- Audit log CREATE con empleadoId
- Solo usuarios con `MANAGE_PROYECTOS` (GERENTE_GENERAL, CISO)

### 3. Componente formulario (`src/app/servicios/nuevo-servicio-form.tsx`)
- `NuevoServicioForm` con react-hook-form + zodResolver
- Warning de precaución sobre nombre único
- Manejo de errores del backend (setError root)
- Solo visible para GERENTE_GENERAL

### 4. Integración UI (`src/app/servicios/servicios-list.tsx`)
- Botón "Nuevo servicio" en header (solo GERENTE_GENERAL)
- FormModal con NuevoServicioForm
- Refetch automático al crear exitosamente

## Archivos modificados
- `src/shared/validation/servicios.ts` (nuevo)
- `src/shared/validation/index.ts` (export schema)
- `src/app/api/servicios/route.ts` (POST handler)
- `src/app/servicios/nuevo-servicio-form.tsx` (nuevo)
- `src/app/servicios/servicios-list.tsx` (FormModal + botón)
- `.opencode/workflow/STATE.md` (US-054 + US-055)

## Decisiones técnicas
- Seguir patrón existente de NuevoClienteForm para consistencia
- Warning de precaución en el formulario ya que `nombre` es `@unique` en Prisma
- Solo GERENTE_GENERAL puede crear servicios (MANAGE_PROYECTOS incluye CISO pero se restringe a GERENTE_GENERAL en UI)
