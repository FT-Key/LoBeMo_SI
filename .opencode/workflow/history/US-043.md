# US-043 — Kanban para Tareas

## Estado: 🔄 In Progress (PR #80 → dev)
## Prioridad: Media
## Sprint: 5

## Problema
Las tareas se muestran como lista scrollable sin visibilidad visual del flujo.

## Solución implementada

### 1. Campo `orden` en Prisma
- Campo `Int @default(0)` en modelo Tarea
- Migración: `20260907075122_add_orden_to_tareas`

### 2. Dependencias
- `@dnd-kit/core`
- `@dnd-kit/sortable`
- `@dnd-kit/utilities`

### 3. Endpoint `PATCH /api/tareas/[id]/orden`
- Actualiza estado y orden de una tarea
- Valida que el proyecto no esté cerrado

### 4. Componente `KanbanBoard`
- 4 columnas: Pendiente, En Progreso, Completada, Cancelada
- Drag-and-drop para mover entre columnas
- Reordenamiento dentro de cada columna
- Cards con título, prioridad, asignado y fecha límite

### 5. Toggle en proyecto-detalle
- Botones para cambiar entre vista Lista y Kanban
- Iconos `LayoutList` y `Columns3` de lucide-react
