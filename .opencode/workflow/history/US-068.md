# US-068: Fix precio string bug en creación de servicios

## Resumen
**Bug**: Al crear un servicio, el campo `precioBase` falla la validación porque el input HTML tipo `number` devuelve un string, pero el schema Zod espera un `z.number()`.

**Error reportado**: "Se esperaba número y se ingresó string"

## Archivos modificados
- `src/app/servicios/nuevo-servicio-form.tsx`: Agregado `valueAsNumber: true` al register de `precioBase`

## Solución
Usar `register("precioBase", { valueAsNumber: true })` para que react-hook-form convierta automáticamente el valor del input a número antes de la validación Zod.

## Resultado
- ✅ Build exitoso
- ✅ Validación funciona correctamente
- ✅ Precio se envía como número al API
