# US-069: Corrección de bugs menores - Acciones de auto-modificación

## Descripción
Corrección de bugs de seguridad/UX relacionados con acciones que un usuario puede realizar sobre su propia cuenta de forma indebida.

## Bugs detectados

### 1. Self-deactivation (UI) — ALTO
- **API**: Ya tiene prevención (`api/empleados/[id]/route.ts:118-123`)
- **UI**: El botón "Desactivar" se muestra para el usuario actual
- **Fix**: Pasar `sessionUserId` al componente y deshabilitar el botón para uno mismo + mostrar error cuando la API rechaza

### 2. Self-role-change — CRÍTICO
- **Endpoint**: PUT `api/empleados/[id]/route.ts`
- **Problema**: Un GERENTE_GENERAL puede cambiar su propio rol
- **Fix**: Bloquear cambio de rol propio en el API

### 3. Self-assignment-removal — MEDIO
- **Endpoint**: DELETE `api/asignaciones/[id]/route.ts`
- **Problema**: Un usuario puede eliminarse de un proyecto
- **Fix**: Bloquear auto-eliminación de asignación en el API

### 4. Self-password-change sin verificar contraseña actual — MEDIO
- **Endpoint**: PUT `api/empleados/[id]/route.ts`
- **Problema**: Un usuario puede cambiar su contraseña sin verificar la actual
- **Fix**: Requerir `currentPassword` cuando el usuario edita su propia contraseña

## Archivos a modificar
- `src/app/empleados/page.tsx` — pasar sessionUserId

- `src/app/api/empleados/[id]/route.ts` — self-role-change guard + self-password guard

- `src/shared/validation/empleados.ts` — agregar currentPassword opcional
