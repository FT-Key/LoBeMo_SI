## Implementación

### 1. Modelo Prisma `EvidenciaPentest`
- Campos: hallazgoId (FK con onDelete Cascade), nombreArchivo, mimeType?, tamanio?, storageKey unique, createdAt
- Relación: HallazgoPentesting → evidencias[]
- Migración: `20260907190201_add_evidencia_pentest`

### 2. Endpoints
- `GET /api/hallazgos-pentesting/[id]/evidencias` — lista archivos (auth: creador o CISO/GERENTE)
- `POST` — upload multipart a R2 (misma validación que /api/upload: MIMES + 25MB) + audit CREATE
- `GET .../evidencias/[evidenciaId]` — redirect a presigned URL (ver/descargar, preview de imágenes)
- `DELETE .../evidencias/[evidenciaId]` — borra de R2 (tolerante a fallo) + DB + audit DELETE

### 3. UI
- `src/components/pentesting/evidencias-hallazgo.tsx` — drag & drop, preview de imágenes, lista con tamaño/fecha, ver/descargar, eliminar (solo con permiso)
- `hallazgo-detalle.tsx` — sección de archivos integrada (preserva evidencias al editar/aprobar)
- `pentesting/[id]/page.tsx` — include evidencias ordenadas
