# US-053: Fix rutas rotas búsqueda global, CSP R2, input evaluación

## Resumen
Corrección de 4 bugs reportados por el usuario: 404 al buscar cliente, tareas no clickeables en búsqueda, CSP bloqueando imágenes R2, y input de evaluación sin onChange.

## Estado
✅ Completado — PR #90 → dev (merged)

## Cambios

### 1. Página detalle clientes/[id] (CRÍTICO)
- **Problema**: `/clientes/[id]` no existía → 404 desde búsqueda global
- **Archivo nuevo**: `src/app/clientes/[id]/page.tsx`
- Server component con AdminSidebar, muestra datos del cliente, contacto, proyectos asociados

### 2. Búsqueda global: tareas clickeables (ALTO)
- **Problema**: `href: null` para tareas → no hacía nada al clickear
- **Archivo**: `src/app/api/search/route.ts`
- Fix: incluir `proyectoId` en select, generar `href: /proyectos/${proyectoId}`

### 3. CSP permite R2 Cloudflare (ALTO)
- **Problema**: `img-src` solo permitía `'self'` + unsplash → bloqueaba imágenes de R2
- **Archivo**: `next.config.ts`
- Fix: agregar `https://*.r2.cloudflarestorage.com` y `data:` a `img-src`, `connect-src`

### 4. Input evaluación capacitación (MEDIO)
- **Problema**: Input con `value` pero sin `onChange` → valor se perdía al re-render
- **Archivo**: `src/components/capacitaciones/capacitacion-detalle.tsx`
- Fix: agregar `onChange` que actualiza estado local, mantener `onBlur` para PATCH
