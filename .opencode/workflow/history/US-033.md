## Estado: ✅ Completada

## Problema
- 6 endpoints sin verificación de rol (clientes CRUD, proyectos GET, propuestas GET, servicios GET)
- 6+ patrones distintos de verificación de roles dispersos en el código
- `session.user.rol` es `string`, no usa el enum `Rol` de Prisma
- Sin middleware de autorización centralizado

## Solución

### 1. Nuevo archivo `src/lib/api-auth.ts`
HOF `withRole()` que encapsula auth + verificación de rol:
```ts
export function withRole(allowedRoles: Rol[], handler) {
  return async (request, ctx) => {
    const session = await auth()
    if (!session?.user) {
      return NextResponse.json({ error: "No autenticado" }, { status: 401 })
    }
    if (!allowedRoles.includes(session.user.rol)) {
      return NextResponse.json({ error: "No autorizado" }, { status: 403 })
    }
    return handler(request, ctx, session)
  }
}
```
