# US-049 — Historial Actividad en Dashboard

## Estado: ✅ Done
## Prioridad: Baja
## Sprint: 3
## Rama: feat/US-049-actividad-dashboard → dev

## Problema
El audit log solo se ve en `/auditoria`. Sin visibilidad rápida en dashboard.

## Solución

### 1. Endpoint `GET /api/dashboard/actividad`
Últimas 20 acciones del audit log con info del empleado.
- `src/app/api/dashboard/actividad/route.ts` (nuevo)
- Protegido con `ROLES.VIEW_DASHBOARD` (Gerente, CISO, Administración) para que los 3 roles del dashboard puedan verlo — no se usa `VIEW_AUDIT_LOG` (solo Gerente) para evitar 403 en CISO/Admin
- `orderBy createdAt desc, take 20, include empleado { id, nombre, apellido, email }`

### 2. Sección "Actividad Reciente" en dashboard
Lista con avatar, acción, entidad, timestamp relativo.
- `src/components/dashboard/actividad-reciente.tsx` (nuevo, client component)
- TanStack Query (`["dashboard-actividad"]`, staleTime 60s) → `fetch /api/dashboard/actividad`
- Avatar: iniciales nombre+apellido (`bg-primary/10 text-primary`), "•" si es Sistema
- Badge acción CREATE/UPDATE/DELETE (verde/azul/rojo, mismo patrón que audit-log-list)
- Timestamp relativo en español: "ahora mismo / hace X min / hace X h / hace X d / fecha"
- Card glassmorphism (`bg-surface/50 backdrop-blur-sm rounded-2xl border-border`) según DESIGN_SYSTEM
- Estados: loading (spinner), error, empty ("Sin actividad registrada")
- Integrado en `src/app/dashboard/dashboard-content.tsx` como sección final `<ActividadReciente />`
