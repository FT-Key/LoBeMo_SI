# US-066: Fix email redirect @lobemo.com

## Objetivo
Corregir el sistema de redireccionamiento de correos @lobemo.com para que funcione correctamente en modo desarrollo/testing.

## Problema detectado
1. `SMTP_REDIRECT_TO` no estaba configurado en `.env.local`
2. 4 rutas de API no usaban `resolverDestinatario()` para redirigir emails
3. Código duplicado muerto en `src/lib/email.ts`

## Cambios realizados

### .env.local
- Agregado `SMTP_REDIRECT_TO=fr4nc0t2@gmail.com`

### .env.example
- Mejorada documentación de `SMTP_REDIRECT_TO` con explicación de uso dev/producción

### Rutas de API corregidas (import + resolverDestinatario)
- `api/tareas/route.ts:143` — email de asignación de tarea a empleado
- `api/tareas/[id]/route.ts:171` — email de tarea crítica completada al CISO
- `api/asignaciones/route.ts:152` — email de asignación a proyecto
- `api/propuestas/[id]/enviar/route.ts:49` — email de propuesta a cliente

### Limpieza de código muerto
- Eliminado `src/lib/email.ts` (duplicado de utils.ts, nunca importado)
- Actualizado `src/lib/email.test.ts` para importar desde `@/lib/email-templates`

## Cómo funciona
Cuando `SMTP_REDIRECT_TO` tiene un valor, cualquier email con destino `*@lobemo.com` se redirige a esa dirección. Para desactivar en producción, dejar la variable vacía o comentarla.
