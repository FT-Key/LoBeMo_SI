# US-058: Evidencia pentesting — Fixes

## Resumen
Fixes de UX e integridad en el módulo de evidencias de pentesting: tamaño de imágenes, apertura de PDFs y borrado limpio de R2.

## Cambios realizados

### 1. Imágenes: sin recorte (`evidencias-hallazgo.tsx`)
- **Antes**: `object-cover` recortaba las imágenes (evidencia técnica cortada)
- **Ahora**: `object-contain` muestra la imagen completa dentro del contenedor
- Altura máxima: `max-h-48` (192px) en vez de `max-h-40` (160px)

### 2. PDFs en nueva pestaña (`evidencias-hallazgo.tsx`)
- Label diferenciado: "Abrir PDF" para archivos PDF, "Descargar" para otros
- Imágenes ya abren en nueva pestaña (el link envuelve la imagen)
- Iconos por tipo: 🖼 imágenes, 📄 PDFs, 📝 Word, 📊 Excel, 📎 otros

### 3. Borrado R2 cascade (`[id]/route.ts`)
- **Bug**: Al eliminar un hallazgo, `onDelete: Cascade` solo limpiaba la DB. Las evidencias en R2 quedaban huérfanas (leak de storage)
- **Fix**: Antes de `prisma.hallazgoPentesting.delete()`, se iteran las evidencias y se llama `deleteFromR2()` para cada una
- Audit log ahora incluye `evidenciasEliminadas` en el detalle

## Archivos modificados
- `src/components/pentesting/evidencias-hallazgo.tsx` — fixes UI
- `src/app/api/hallazgos-pentesting/[id]/route.ts` — fix cascade R2
