# US-042 — Dashboard del Empleado

## Estado: 🔄 In Progress (PR #79 → dev)
## Prioridad: Media
## Sprint: 4

## Problema
No hay vista personal consolidada de tareas y proyectos por empleado.

## Solución implementada

### 1. Endpoint `GET /api/dashboard/empleado`
- Retorna: proyectos activos, tareas (pendientes/completadas), estadísticas por estado y prioridad
- Accesible para todos los roles (autenticado)

### 2. Página `/mi-dashboard`
- Server component con carga de datos vía Prisma
- Serialización de fechas para client component

### 3. Componente `MiDashboardContent`
- 4 cards de resumen (proyectos activos, tareas pendientes, completadas, total)
- Gráficos de barras: tareas por estado y por prioridad
- Lista de proyectos activos con link al detalle
- Lista de tareas con estado, prioridad, proyecto y fecha límite

### 4. Sidebar
- "Mi Dashboard" agregado en sección "Principal" para todos los roles
